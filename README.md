# Python Mini Projects

This repository contains a collection of basic Python projects created for learning and practice. Each project focuses on improving programming logic and Python fundamentals.


## 📂 Projects Included

- Dice Roller 🎲  
- BMI Calculator ⚖️  
- Countdown Timer ⏳  
- Random Quote Generator 💬  
- Unit Converter 🔄  
- Rock Paper Scissors ✊✋✌️


## 🚀 How to Run

Run any project using this format:

```bash
unit_converter/main.py
countdown_timer/main.py
```

## 🛠️ Tools Used

- Python 3
- Built-in Python Libraries
